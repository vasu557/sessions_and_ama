
## 1. Boorle Sowmya Sri Lakshmi — What is EC2?

**EC2 (Elastic Compute Cloud)** is an AWS service that provides **virtual servers** to run applications in the cloud.

> **EC2 = Virtual server in AWS**

---

## 2. Md Musharaf — What is Virtualization?

**Virtualization** is the process of creating **virtual machines from a physical machine** using software.

> **One physical server → Multiple virtual machines**

---

## 3. Vikas Mehta — Which server is used to store data in AWS?

It depends on the type of data:

- **RDS** → Relational database
- **DynamoDB** → NoSQL database
- **S3** → Files, images, videos

> There is no single AWS service for all types of data.

---

## 4. Saurav — Difference between Docker and Kubernetes?

| Docker | Kubernetes |
|---|---|
| Creates and runs containers | Manages containers |
| Container platform | Container orchestration platform |
| Runs containers | Deploys, scales and manages containers |

> **Docker runs containers; Kubernetes manages containers.**
