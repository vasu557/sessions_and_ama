# Questions and Answers

## 1. Adhikya Edammala — What is Context Cost?

**Context cost** is the amount of computational resources and money required to process the context provided to an AI model.

Context can include:

* User prompts
* Conversation history
* Documents
* System instructions
* Previous model responses

The larger the context, the more **tokens** the model needs to process.

### Example

```text
Prompt + Conversation History + Documents = Context
```

More context means:

* More tokens
* Higher API cost
* More processing time
* Potentially higher latency

Therefore, keeping the context **small and relevant** helps reduce cost and improve performance.

## 2. Allanki VV Manikanta Sai — When Do We Get a Validation Error?

A **validation error** occurs when the data provided to an application or API does not satisfy the required rules, format, or data type.

### Common situations

* A required field is missing.
* The wrong data type is provided.
* A value is outside the allowed range.
* An invalid parameter is sent to an API.
* Input does not match the expected schema.
* An email address or other field has an invalid format.

### Example

Suppose an API expects `age` to be a number:

```json
{
  "age": "twenty"
}
```

Since `"twenty"` is a string instead of a number, the API may return a **validation error**.

## 3. Boorle Sowmya Sri Lakshmi — What Is Meant by Seam?

A **seam** is a place in software where we can separate, replace, or modify one part of a system without making major changes to the rest of the system.

Seams are useful for:

* Testing individual components
* Replacing dependencies
* Mocking external services
* Making code easier to maintain
* Reducing dependencies between components

### Example

Suppose an application gets information from an external API.

```text
Application → API Client → External API
```

The **API Client** can act as a seam. During testing, we can replace the real API client with a mock implementation.

```text
Application → Mock API Client
```

This allows us to test the application without calling the real external API.

## 4. Md Musharaf — What Is Token Counting?

**Token counting** is the process of determining how many tokens are present in text that is sent to or generated by an AI model.

A token can be:

* A complete word
* Part of a word
* Punctuation
* A special character

The exact number of tokens depends on the tokenizer and the model being used.

### Example

```text
Hello, world!
```

The model's tokenizer converts this text into tokens before processing it.

### Why is token counting important?

Token counting helps us:

* Estimate API costs
* Stay within context limits
* Reduce prompt size
* Monitor input and output usage
* Improve application performance

In general:

```text
More tokens → Higher processing cost
Fewer relevant tokens → Lower processing cost
```

## 5. Nayunipatruni Harsha Vardhan — How to Reduce Context Size?

Context size can be reduced by sending only the information that is necessary for the current task.

### Methods to reduce context size

1. **Remove irrelevant information**

   * Do not send unnecessary conversation history or documents.

2. **Summarize older conversations**

   * Replace long conversation history with a short summary.

3. **Use relevant document retrieval**

   * Retrieve only the sections of a document that are required.

4. **Remove duplicate information**

   * Avoid sending the same information multiple times.

5. **Limit conversation history**

   * Keep only the most relevant previous messages.

6. **Use concise instructions**

   * Avoid unnecessarily long prompts.

7. **Use structured data**

   * When appropriate, use concise JSON or key-value data instead of verbose text.

### Simple idea

```text
Remove unnecessary context
          ↓
Reduce number of tokens
          ↓
Lower cost
          ↓
Faster processing
```

The goal is not simply to reduce context, but to **keep only useful and relevant context**.

## 6. Vikas Mehta — Use of Context API in React

The **Context API** in React is used to share data between components without passing props through every level of the component tree.

It is useful for data that needs to be accessed by many components, such as:

* Theme
* User authentication
* Language preferences
* Application settings
* Global configuration

### Main parts of Context API

React Context commonly uses:

1. `createContext()`
2. `Provider`
3. `useContext()`

### Example

```jsx
import { createContext, useContext } from "react";

const ThemeContext = createContext("light");

function App() {
  return (
    <ThemeContext.Provider value="dark">
      <Home />
    </ThemeContext.Provider>
  );
}

function Home() {
  const theme = useContext(ThemeContext);

  return <div>Current theme: {theme}</div>;
}
```

### How it works

```text
ThemeContext.Provider
          ↓
        Home
          ↓
useContext(ThemeContext)
          ↓
       "dark"
```

The `Provider` makes the value available to its child components.

The `useContext()` hook allows a component to access that value without manually passing it through props.

### Benefits

* Avoids **prop drilling**
* Makes shared data easier to access
* Simplifies application-wide settings
* Useful for themes, authentication, and preferences

### Important Note

Context API is useful for sharing data, but it is not always the best choice for all application state. For complex state management, dedicated state-management solutions may be more appropriate.
